# WebStudio

A responsive business landing page developed as part of the GoIT Full-Stack Developer course.

## About the Project

WebStudio is a landing page for a digital agency. This project builds upon the previous homework and focuses on working with SVG icons, background images, CSS transitions, hover effects, and decorative elements.

## Features

- Semantic HTML5 markup
- Flexbox layout
- SVG sprite integration using `<svg>` and `<use>`
- Background images with gradient overlays
- CSS hover and focus effects
- Animated transitions
- Portfolio cards with animated overlays
- Team and social media sections
- Reusable CSS styles

## Technologies

- HTML5
- CSS3
- Flexbox
- SVG
- Google Fonts
- Modern Normalize

## Learning Objectives

- Working with SVG sprites and vector icons
- Applying CSS pseudo-elements

- Implementing hover and focus interactions
- Using CSS transitions and transforms
- Improving page structure and visual presentation
